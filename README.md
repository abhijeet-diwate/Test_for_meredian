# Student Management System

## Overview
The Student Management System is a simple Python project designed to manage student records. It allows users to add students, view student information, and calculate average marks.

## Features
- Add a new student
- View all student records
- Calculate average marks
- Assign grades based on average marks
- Simple command-line interface

## Technologies Used
- Python 3
- Python standard library

## Project Structure
- `main.py` — Contains the main application logic.
- `requirements.txt` — Lists project dependencies.

## How to Run

1. Install Python 3.
2. Clone this repository.
3. Open a terminal in the project directory.
4. Run:

```bash
python main.py
```

## Grading Criteria
- A: Average marks >= 90
- B: Average marks >= 75
- C: Average marks >= 60
- D: Average marks >= 40
- F: Average marks < 40
